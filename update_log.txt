SF6 Color Collection Builder v0.1.2

Feature release for scan diagnostics and loose folder support.

Changes:
- Scan immediate top-level loose mod folders in addition to zip files.
- Recursively scan files inside each loose mod folder.
- Keep SF6 color structure filtering with support for wrapper/submod folders.
- Add structured scan issue reporting and local scan.log output beside the executable.
- Show scan issue count and first affected package/path in the status bar.
- Continue scanning valid mods when a zip, folder, or modinfo.ini has warnings.
- Export colors assigned from loose folder sources.
- Load previews from both zip packages and loose folders.

SF6 Color Collection Builder v0.1.1

Maintenance release for startup stability, scan filtering, and update support.

Changes:
- Added a portable auto-updater for future releases.
- Moved settings from the Windows registry to local settings.ini beside the executable.
- Prevented startup crash loops by clearing remembered mod folder on scan failure.
- Hardened zip scanning against malformed modinfo.ini files, percent signs, bad zips, and loose/non-SF6 color files.
- Require supported color files to be inside natives/stm/product/model/esf while still allowing submod wrapper folders.

SF6 Color Collection Builder v0.1.0

Initial public release.

Features:
- Scan SF6 color mod zip files.
- Detect modinfo, preview images, characters, costumes, and normal/DX/EX color slots.
- Assign source slots into a custom collection.
- Save/export a Fluffy Mod Manager compatible collection zip.
- Reopen app-created collection zips while preserving source mod names and original source slots.
- Remember last folders and window size.
- Includes GitHub update-check support.
